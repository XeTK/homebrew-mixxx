# Adopt engineering standards v1

## Context

On 2026-10-08 the owner instructed that
[engineering-standards](https://gitea.xetk.co.uk/xetk/engineering-standards)
be applied to this repo.

## Decision

This repo follows engineering-standards **v1** with the profiles
`stack-defaults` and `homelab`. Deviations are recorded in this folder.

## Consequences

- `AGENTS.md`, the pull request template and the issue templates come from
  the standards repo.
- Existing gaps are listed in the adoption pull request and recorded as
  proposed deviations (0002 onwards) until they are closed.
